# Правила работы над проектом

## Ветки и pull request

Каждое крупное изменение выполняй в отдельной ветке и отправляй на ревью через pull request в `main`. К крупным изменениям относятся новые функции, модульный рефакторинг и изменения публичных интерфейсов или форматов хранения.

Создавай ветку до начала работы. В pull request кратко опиши изменения и результаты проверок. Крупные изменения попадают в `main` через слияние pull request после ревью.
