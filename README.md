# Мои миры — локальный каталог

Каталог показывает книжные и игровые проекты, открывает Markdown, хранит заметки и поддерживает локальную и облачную озвучку.

## Запуск

Нужен Python 3.9 или новее. Из папки каталога:

```sh
python3 server.py
```

Откройте `http://127.0.0.1:8765`. Сервер доступен только на этом компьютере. Для остановки нажмите `Ctrl+C`. Сервер продолжает генерацию в фоне, пока запущен; прерванные задания общей генерации восстанавливаются при запуске. Если во время перезапуска выполнялась перегенерация отдельного фрагмента, её нужно запустить снова.

По умолчанию книги берутся из `~/Documents/stories/books`, игры — из `~/Development/games`. Эти пути не зависят от расположения каталога. Модели и пользовательские данные остаются в прежних папках. Реальный Python для Piper и Qwen берётся из соответствующих виртуальных окружений, независимо от Python, которым запущен сервер.

Для разработки используйте `python3 dev_server.py` вместо обычного запуска. Сервер перезапускается после изменений серверных Python-файлов и `config.local.json`. После правок HTML, CSS и JavaScript достаточно обновить страницу в браузере. Ctrl+C останавливает dev-сервер. Перезапуск прерывает текущий вызов модели. Очередь озвучки восстанавливается штатным механизмом при запуске.

## Перемещение

Можно переместить всю папку `project-catalog` в `~/Development`. Переносите папку целиком, включая скрытые файлы: в них находятся Git, заметки, голоса и готовая озвучка. Обычное клонирование из Git эти локальные данные и модели не переносит. Перед перемещением дождитесь окончания генерации и остановите сервер, затем запустите его из нового расположения.

После переноса проверьте локальную озвучку: виртуальные окружения Python содержат привязанные к исходному расположению служебные скрипты. Если модель не запускается, создайте окружения заново; сами модели, голоса, задания и аудио при этом переустанавливать не нужно.

## Настройки

Настройки необязательны. Их можно изменить на странице «Настройки» сайта или вручную: скопируйте `config.example.json` в `config.local.json` и измените нужные поля. Предпочтения интерфейса сохраняются в браузере и применяются сразу; пути и параметры сервера — после его перезапуска. Относительные пути отсчитываются от папки каталога; `~` обозначает домашнюю папку.

| Поле | Назначение |
| --- | --- |
| `books_root`, `games_root` | Корневые папки проектов |
| `voices_dir` | Папка голосов Piper |
| `qwen_tts_model`, `qwen_asr_model` | Пути к локальным моделям синтеза и распознавания |
| `piper_python`, `mlx_python` | Интерпретаторы виртуальных окружений с зависимостями моделей |
| `port` | Локальный порт сайта |
| `qwen_timeout`, `piper_timeout`, `asr_timeout` | Время ожидания моделей в секундах |
| `piper_sentence_silence` | Пауза Piper между предложениями в секундах |
| `openai_model` | Название модели озвучивания OpenAI |

После изменения путей и параметров моделей или сервера перезапустите сервер. Если изменили порт, откройте новый адрес `http://127.0.0.1:НОВЫЙ_ПОРТ`. При смене пути модели или параметра паузы Piper используется отдельный кэш. Если заменить файлы модели по прежнему пути, для новой озвучки используйте сброс кэша в интерфейсе.

Для OpenAI задайте переменную окружения `OPENAI_API_KEY` перед запуском сервера. Ключ в конфигурационный файл не записывается. Запросы к OpenAI отправляют выбранный текст во внешний API и могут тарифицироваться отдельно.

## Данные

Заметки находятся в `.notes.sqlite3`, теги — в `tags.json`, пользовательские голоса — в `.voice-profiles` и `.voice-sample`, кэш — в `.speech-cache`, задания и готовые фрагменты — в `.speech-jobs`. Эти файлы и папки с моделями исключены из Git. Смена настроек путей к книгам или играм не переносит заметки и задания автоматически.

## Структура

- `server.py` — HTTP-маршруты и запуск.
- `app_config.py`, `config_store.py`, `config.example.json` — настройки, их проверка и безопасное сохранение.
- `catalog_paths.py`, `notes_store.py` — проверка путей и хранение заметок.
- `speech_jobs.py`, `speech_text.py`, `speech_service.py`, `speech_engines.py` — очередь, разбиение текста, политика кэша и адаптеры моделей. Очередь обращается к сервису синтеза напрямую.
- `web/` — интерфейс: разметка, стили, модули боковой панели, Markdown, заметок и озвучивания.
- `tests/` — проверки данных, API и совместимости настроек.

Корневой `index.html` временно оставлен для уже работающего старого процесса сервера. Текущий сервер использует файлы из `web/`; новые изменения интерфейса нужно вносить туда.

## Проверки

```sh
python3 -m unittest discover -s tests -v
node tests/test_web.mjs
node tests/test_settings_web.mjs
```

Тесты HTTP используют временный каталог и локальный порт и могут пропускаться в окружении, где создание локальных сокетов запрещено. Они не используют настоящие модели, голоса или файлы проектов.

### Сравнение озвучки

В панели озвучивания режим «Плавные стыки» воспроизводит фрагменты без независимой нормализации и сглаживает их края. «Оригинал» позволяет услышать исходные WAV, а «Прежняя нормализация» сохраняет старое поведение для сравнения. Дополнительная пауза между фрагментами выбирается отдельно; предпочтения хранятся в браузере. Изменение режима не перегенерирует аудио.

В режиме создания голоса можно привязать новый нейтральный или шепчущий образец к существующему голосу. У каждого сохраняется своя запись и расшифровка; при прослушивании манера выбирается перед генерацией. Старые голоса не переносятся и не перезаписываются. Чтобы сервер увидел новый API, его требуется перезапустить.

[Результаты и команды запуска](reports/speech-experiments.md). Скрипты в `experiments/` предназначены для локальных исследований; они не меняют настройки приложения. `whisper_icl.py` вызывает ICL напрямую, чтобы исследовать штраф ниже 1,5, который обычный путь библиотеки принудительно ограничивает. Для оценки шёпота и тембра требуется прослушивание; локальное распознавание служит только дополнительной проверкой возможных пропусков.


### Экспериментальный синтетический голос

В панели «Озвучивание» выберите «VoiceDesign 1.7B» и задайте тип голоса и примерный возраст. Настройки сохраняются в браузере и входят в ключ кэша. Первый фрагмент создаётся по описанию и сохраняется как эталон; последующие фрагменты генерирует Base по этому образцу. Чтобы использовать тот же голос на других страницах, после подготовки первого фрагмента нажмите «Сохранить эталон голоса» и задайте имя. Сохранённый голос появится в списке «Мои голоса»; его эталон хранится отдельно от озвучки страницы. Запись диктора не нужна. Возраст и тип являются ориентиром; одинаковый тембр не гарантирован. Предпрослушивание отдельно создаёт голос по описанию. Озвучка выполняется локально; модель загружается для каждого фрагмента, поэтому подготовка может быть медленной. Для работы нужны локальные веса `models/qwen3-tts-1.7b-voicedesign` и существующее окружение MLX `.clone-env`. Режим клонирования остаётся отдельным. После изменения кода перезапустите сервер и обновите страницу.
